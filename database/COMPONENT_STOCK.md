# ยืมหลายชุดและของย่อยตามจำนวน

หน้ารายการสิ่งของเลือกได้สองแบบ: ชุดมาตรฐานจำนวนหลายชุด หรือระบุจำนวนรวมของของย่อยแต่ละชนิด เช่น พานทอง 3 ใบและพานเงิน 1 ใบ ใส่ 0 สำหรับชนิดที่ไม่ต้องการ ผู้ยืมคนเดิมส่งคำขอของชุดเดิมเพิ่มได้เมื่อของย่อยยังคงเหลือ

ระบบเก็บสต็อกจริงแยกใน `item_components.stock_total` และ `stock_available` ยอดชุดพร้อมยืมใน `items` คือจำนวนชุดมาตรฐานที่ประกอบได้จากของย่อยที่พร้อมทั้งหมด การอนุมัติตัดเฉพาะของย่อยที่เลือกและตรวจยอดจองมาตรฐานก่อนเสมอ คำขอที่ยังไม่อนุมัติยังไม่ตัดสต็อก

เมื่อมีของย่อยเหลือที่ประกอบเป็นชุดไม่ครบ จะแสดง “ของไม่ครบชุด” แต่ยังเปิดเลือกของย่อยที่เหลือได้ หากยังประกอบชุดเต็มได้บางชุด ก็ยืมชุดมาตรฐานตามจำนวนที่มีได้เช่นกัน

ยอดของย่อยที่ส่งมอบเก็บไว้ใน `borrow_item_components.quantity_borrowed` เพื่อใช้แสดงใบส่งมอบ ประวัติ และตรวจรับคืน ส่วนค่า NULL คือคำขอชุดมาตรฐาน/ข้อมูลเก่า ซึ่งคำนวณจากจำนวนต่อชุดใน snapshot

ชุดมาตรฐานคืนแยกบางชุดได้ สำหรับรายการที่กำหนดจำนวนของย่อยเอง ให้ตรวจรับรายการนั้นพร้อมกันทั้งหมด และแจ้งชำรุด/สูญหายแยกตามชนิดของย่อย โดยห้ามเกินจำนวนที่ส่งมอบ ของย่อยที่คืนสภาพดีกลับเข้าสต็อกทันที การชดใช้ด้วยของแทนคืนเฉพาะชนิดนั้น ส่วนการจ่ายค่าชดใช้ตัดยอดรวมเฉพาะชนิดที่เสียหาย

อัปเกรดฐานข้อมูลเดิม:

```powershell
C:\xampp\php\php.exe database/migrate_component_stock.php
```

หรือใช้ migration หลัก `database/migrate.php` การอัปเกรดเก็บคำขอเดิมไว้และคืนยอดของย่อยที่เคยถูกกันไว้ทั้งชุดแต่ไม่ได้ส่งมอบ การติดตั้งใหม่ใช้ `database/profix.sql` ซึ่งมีคอลัมน์ใหม่แล้ว

ทดสอบในฐานข้อมูลแยกที่สร้างใหม่และลบหลังทดสอบ:

```powershell
$env:PROFIX_DB_NAME='profix_test_component_counts'
C:\xampp\php\php.exe database/test_component_quantities.php
Remove-Item Env:\PROFIX_DB_NAME
```
