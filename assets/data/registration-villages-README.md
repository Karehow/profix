# รายชื่อหมู่บ้านสำหรับหน้าสมัครสมาชิก

ไฟล์ `registration-villages.json` ใช้รหัสตำบลตามฐานข้อมูลเดิมของโปรเจ็กต์ ค่าในแต่ละ array เรียงตามเลขหมู่ โดย index 0 คือหมู่ 1 ชื่อซ้ำคนละหมู่ต้องคงไว้
ข้อมูลเป็นรายการช่วยกรอก ไม่ใช่ทะเบียนทางราชการที่อัปเดตสด มีตัวเลือกกรอกเองสำหรับรายการที่ตกหล่นหรือชื่อที่ต้องแก้ไข
ตำบลในฐานข้อมูลเดิมที่ไม่มีข้อมูลในไฟล์นี้ยังใช้ตัวเลือกกรอกเองได้ ไม่ได้แก้เขตการปกครองเดิมในงานนี้

แหล่งข้อมูลที่ตรวจอ่านวันที่ 2026-09-12 (เก็บเฉพาะชื่อหมู่บ้านและเลขหมู่ ไม่มีข้อมูลบุคคล):

- คลองเมือง: [อบต.คลองเมือง หน้า 3 ของแผนพัฒนาท้องถิ่น 2561–2564](https://khlongmueang.go.th/fileupload/8673241008.pdf)
- หินโคน: [อบต.หินโคน ข้อมูลทั่วไป](https://hinkhonlocal.go.th/index.php/2020-08-18-14-37-04/2020-08-24-14-14-37)
- จักราช ทองหลาง สีสุก หนองขาม หนองพลวง ศรีละกอ: ตารางหมู่บ้านรายตำบลของ Noplink เข้าผ่าน [รายชื่อตำบลอำเภอจักราช](https://noplink.com/postcode_a.php?a=จักราช&p=นครราชสีมา) แล้วเลือกตำบล

เมื่อแก้ข้อมูล ให้ตรวจสอบชื่อและเลขหมู่กับหน่วยงานในพื้นที่ก่อน ห้ามเรียงชื่อใหม่ใน array เพราะจะเปลี่ยนเลขหมู่
