# พิกัดอ้างอิงหมู่บ้านสำหรับการค้นหาที่อยู่

`registration-village-locations.json` เก็บพิกัดที่ตรวจสอบแหล่งข้อมูลแล้ว โดยผูกกับจังหวัด อำเภอ ตำบล เลขหมู่ และชื่อหมู่บ้านครบทุกส่วน ไม่จับคู่ด้วยชื่ออย่างเดียว

บ้านบุ หมู่ 8 ตำบลหนองพลวง อำเภอจักราช จังหวัดนครราชสีมา:
- รหัสที่ใช้ในโปรเจ็กต์: จังหวัด 19 / อำเภอ 3006 / ตำบล 300607 / หมู่ 8
- ละติจูด 15.090940 / ลองจิจูด 102.397999
- [เอกสารรายชื่อหมู่บ้านเน็ตประชารัฐ 24,700 หมู่บ้าน จากกระทรวงดิจิทัลเพื่อเศรษฐกิจและสังคม](https://www.mdes.go.th/uploads/tinymce/source/%E0%B8%A8%E0%B8%82/filedownload/24700.pdf) หน้า PDF 128 ลำดับ 6005 ตรวจอ่าน 2026-09-12

พิกัดนี้เป็นจุดอ้างอิงในหมู่บ้านจากรายการเน็ตประชารัฐ ไม่ใช่ศูนย์กลางทางภูมิศาสตร์หรือพิกัดบ้านเลขที่ของผู้สมัคร
เลือกหมู่บ้านนี้แล้วกดค้นหาโดยไม่กรอกบ้านเลขที่ ระบบจะวางหมุดทันทีจากข้อมูลในเครื่อง ไม่เรียกบริการค้นหาภายนอก
หากกรอกบ้านเลขที่ จะค้นหาบ้านเพิ่มเติมโดยใช้หมู่บ้านเป็นขอบเขต และคงหมุดหมู่บ้านไว้เมื่อบริการค้นหาล้มเหลว
ระบบบันทึกพิกัดเมื่อผู้ใช้ลาก/คลิกเลือกหรือกดยืนยันเท่านั้น เว้นแต่มีผลบ้านเลขที่ตรงตามเงื่อนไขการค้นหา
